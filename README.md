# Engineered Now · Panel de control

App web (instalable en el móvil) con el panel de control de Hunter, JEER e IPAI.

**Abrir:** https://accounting152.github.io/engineerednow-panel/

Los datos (`data.enc.json`) están cifrados con AES-256-GCM y una clave derivada de la contraseña (PBKDF2-SHA256). Sin la contraseña el repositorio no contiene ninguna cifra legible.

## Instalar en el móvil
- **iPhone (Safari):** abrir el enlace → botón Compartir → *Añadir a pantalla de inicio*.
- **Android (Chrome):** abrir el enlace → menú ⋮ → *Instalar aplicación* o *Añadir a pantalla de inicio*.

La primera vez pide la contraseña; con "Recordar en este dispositivo" no la vuelve a pedir.
